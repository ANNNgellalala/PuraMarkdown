# 版本与升级策略（APP 迭代参考）

## 1. 版本号

- 当前：`0.1.0-alpha.1`；所有包**统一版本**（`Directory.Build.props`）。
- 0.x alpha 阶段允许破坏性变更；1.0 后按 [SemVer](https://semver.org/lang/zh-CN/)：
  - MAJOR：公共 API 不兼容；
  - MINOR：新增能力，向后兼容；
  - PATCH：修复，向后兼容。

## 2. 包版本矩阵

当前共 **3 个 NuGet 包**（全部统一版本；0.1.0-alpha.1 只做过本地 `dotnet pack` 验证，未发布到 nuget.org）：

| 包 | 依赖 |
| --- | --- |
| `PuraMarkdown.Syntax` | Markdig 1.5.1（无 Avalonia） |
| `PuraMarkdown` | `PuraMarkdown.Syntax`、Avalonia 12.1.5、Avalonia.Controls.ItemsRepeater 12.0.0、Markdig 1.5.1、JsonSchema.Net 9.6.0 |
| `PuraMarkdown.Plugins` | `PuraMarkdown`、ColorCode.Core 2.0.15、Mermaider 0.15.1 |

- `PuraMarkdown` 已内置原 `PuraMarkdown.Agent`、`PuraMarkdown.Chat`、`PuraMarkdown.Testing` 的内容（C# 命名空间不变）；
- `PuraMarkdown.Plugins` 是原 `PuraMarkdown.Highlighting.ColorCode` 与 `PuraMarkdown.Diagrams.Mermaid` 的合并包，可选引用；
- 已删除的包 id：`PuraMarkdown.Agent`、`PuraMarkdown.Chat`、`PuraMarkdown.Testing`、`PuraMarkdown.Highlighting.ColorCode`、`PuraMarkdown.Diagrams.Mermaid`；
- `samples/**` 均为 `IsPackable=false`，不发布。

宿主升级时必须**同时升级**核心与插件包（`PuraMarkdown` 与 `PuraMarkdown.Plugins`），不要混用版本。`CSharpMath.Avalonia` 只由示例项目 `samples/PuraMarkdown.Plugins.Samples` 引用，不在任何发布包依赖中。详见 [ADR-0027](adr/0027-package-consolidation.md)。

## 3. API 稳定性分级

| 级别 | 承诺 |
| --- | --- |
| 宿主 API（View/Options/Streaming/Events/Theme/Localizer/Limits） | 1.0 后稳定，破坏需 MAJOR |
| 插件 API（IPuraPlugin/Renderer/Inline/Fence/Highlighter/Sanitizer/Agent 组件） | 1.0 后稳定 |
| 高级（RenderContext、BlockRecord、Markdig 扩展） | 尽量兼容，不承诺 |
| 内部（默认渲染器、扫描器） | 随时调整 |

详见 [公共 API 参考](28-公共API参考.md)。

## 4. APP 升级步骤

1. 阅读 [迁移指南](27-迁移指南-0.1.0-alpha.1.md) 的 Breaking 列表；
2. 把包引用收敛到当前 3 个包：**保留** `PuraMarkdown`（内含 Agent/Chat/Testing），可选加 `PuraMarkdown.Plugins`（内含 ColorCode 高亮 + Mermaid）；**删除** `PuraMarkdown.Agent`/`PuraMarkdown.Chat`/`PuraMarkdown.Testing`/`PuraMarkdown.Highlighting.ColorCode`/`PuraMarkdown.Diagrams.Mermaid` 的 `PackageReference`（`using` 与源码不用改）；
3. 所有 PuraMarkdown 包统一到同一版本（`0.1.0-alpha.1`）；
4. 编译后按错误逐项替换旧 API；
5. 跑 Markdown/Agent/流式/主题用例；
6. 如使用自定义插件，确认已实现 `IFenceRenderer`/`IPuraInlineRenderer`；
7. 更新锁文件/本地源缓存。

```bash
dotnet list package | findstr PuraMarkdown
dotnet restore
dotnet build
```

## 5. 发布前检查（库维护者）

- `dotnet build PuraMarkdown.slnx` 0 警告；
- `dotnet test` 全绿；
- `dotnet pack -c Release` 产出 3 个包：`PuraMarkdown.Syntax`、`PuraMarkdown`、`PuraMarkdown.Plugins`（`samples/**` 为 `IsPackable=false`，不产出）；
- README/迁移/API 参考更新；
- 打 tag 并更新 CHANGELOG；
- 1.0 前补充 `PublicAPI.Shipped.txt` 与分析器。

## 6. 兼容性策略

- 新增 API 优先（默认参数/新类型），少改旧签名；
- 删除/重命名先标记 `[Obsolete]` 一个 MINOR 周期（1.0 前可直接删除）；
- 插件契约变更需同时更新官方插件与示例；
- 文档中的示例必须与当前包版本一致。
