# 应用集成指南（账单 APP 等宿主）

> 当前版本：`0.1.0-alpha.1`。本文以**当前实现**为准；历史设计文档见 [文档索引](README.md)。
> 适用：Avalonia 12.1.5 / .NET 10（net10.0）。包 id 与命名空间已于 2026-11-10 统一改名为 `PuraMarkdown.Core` / `PuraMarkdown.Agent` / `PuraMarkdown.Extension`（见 [ADR-0028](adr/0028-package-identity-rename.md)）。

## 1. 选择包

当前共 **3 个包**，版本统一为 `0.1.0-alpha.1`。**包名与 C# 命名空间一一对应**：升级时 `PackageReference` 与 `using` 一起改（[ADR-0028](adr/0028-package-identity-rename.md)）。没有裸 `PuraMarkdown` 包：Avalonia 渲染控件全部在 `PuraMarkdown.Agent`，`PuraMarkdown.Core` 不依赖 Avalonia。

| 需求 | 包 | 命名空间 |
| --- | --- | --- |
| 渲染 Markdown（只读展示，无论是否用 Agent 交互） | `PuraMarkdown.Agent` | `PuraMarkdown.Agent`（控件/管道/主题/选项） |
| `pura-agent` 选择/确认组件 | `PuraMarkdown.Agent` | `PuraMarkdown.Agent` |
| 工具调用（`pura-tool` 围栏、`tool-call` 组件、Chat tool 消息） | `PuraMarkdown.Agent` | `PuraMarkdown.Agent` |
| 聊天列表（消息虚拟化 + 流式槽） | `PuraMarkdown.Agent` | `PuraMarkdown.Agent.Chat` |
| 测试工具（dump/golden/交互/流式驱动） | `PuraMarkdown.Agent` | `PuraMarkdown.Agent.Testing` |
| 只消费语法树/自定义控件（Arc.Avalonia） | `PuraMarkdown.Core` | `PuraMarkdown.Core` |
| 代码高亮 | `PuraMarkdown.Extension` | `PuraMarkdown.Extension.Highlighting.ColorCode` |
| Mermaid 图表 | `PuraMarkdown.Extension` | `PuraMarkdown.Extension.Diagrams.Mermaid` |

`PuraMarkdown.Agent` 依赖 `PuraMarkdown.Core`、Avalonia 12.1.5、ItemsRepeater 12.0.0、Markdig 1.5.1 与 `JsonSchema.Net`（内置 Agent 组件用）；引擎依赖（ColorCode.Core、Mermaider）**只**出现在可选包 `PuraMarkdown.Extension`，`PuraMarkdown.Core`/`PuraMarkdown.Agent` 保持零引擎依赖（ADR-0014）。

```xml
<PackageReference Include="PuraMarkdown.Agent" Version="0.1.0-alpha.1" /><!-- 传递引入 PuraMarkdown.Core -->
<PackageReference Include="PuraMarkdown.Extension" Version="0.1.0-alpha.1" /><!-- 可选：代码高亮 + Mermaid -->
<!-- 无 Avalonia 的纯解析场景只需引 PuraMarkdown.Core -->
```

## 2. 最小接入：只渲染 Markdown

```csharp
using PuraMarkdown.Agent;
using PuraMarkdown.Core.Security;   // PuraLimits 在 Core 包（命名空间 PuraMarkdown.Core.Security）

var pipeline = new PuraPipelineBuilder()
    .UseCommonMark()
    .UseGfm()
    .UseFootnotes()          // 可选：脚注 + 回链
    .UseDefinitionLists()    // 可选：定义列表
    .UseAlertBlocks()        // 可选：> [!NOTE]
    .Build();

var view = new PuraMarkdownView
{
    Options = new PuraMarkdownOptions
    {
        Pipeline = pipeline,
        Theme = PuraTheme.Light,
        Limits = new PuraLimits
        {
            MaxDocumentChars = 2 * 1024 * 1024,
            MaxBlocks = 3000,
        },
    },
};

view.Markdown = billMarkdown;
```

- 控件只做只读渲染，不管理对话/状态；
- 头像、消息气泡、列表容器由宿主负责；
- 主题、字体、颜色通过 `PuraTheme` 定制。

## 3. Agent 交互组件

```csharp
using PuraMarkdown.Agent;

var pipeline = new PuraPipelineBuilder()
    .UseCommonMark()
    .UseGfm()
    .UseAgentComponents()          // 扩展方法：注册 AgentPlugin
    .Build();

view.InteractionOccurred += (_, args) =>
{
    // 宿主决定如何回传 Agent/服务端
    Console.WriteLine($"{args.ComponentType}: {string.Join(",", args.SelectedIds)}");
};
```

- 未调用 `UseAgentComponents()`（或 `UsePlugin(new AgentPlugin())`）时，`pura-agent` 围栏回退为普通代码块；Agent 能力本身在 `PuraMarkdown.Agent` 包内，不需要额外引用包；
- 自定义组件：
  ```csharp
  builder.UseAgentComponent(new RatingParser(), new RatingRenderer());
  ```
  多个插件可向同一 Agent 围栏追加组件，不会重复注册；
- 组件状态按 `ComponentId` 保留，虚拟化回收/重建后恢复；
- 工具调用：`pura-tool`（别名 `pura-tool-call`）围栏与 `pura-agent` 内的 `"type":"tool-call"` 组件同样由 `PuraMarkdown.Agent` 提供，Chat 侧使用 `PuraChatRole.Tool` 与消息上的 tool calls 字段。

## 4. 流式输出

```csharp
var session = view.BeginStreaming();   // 默认异步：后台解析 + UI 合帧
await session.AppendAsync(token.AsMemory());
await session.CompleteAsync();          // 全量校正、组件/高亮落地

// 可选
view.IsStreaming                      // 是否流式中
view.ActiveSession                    // 当前会话
view.AbortStreaming();                // 中断并保留已渲染内容
await session.FlushAsync();           // 截图/导出前强制完成当前缓冲
```

建议：

- `Append`/`AppendAsync` 在 UI 线程调用（内部只入队，不阻塞）；
- `CompleteAsync` 可在后台线程调用（内部回 UI 渲染）；
- 长代码块/组件在 `Complete` 后呈现最终效果；
- 超大未闭合块由 `PuraStreamingOptions.MaxTailChars`（默认 1MB）保护。

## 5. 聊天列表（可选）

```csharp
using PuraMarkdown.Agent.Chat;

var chat = new PuraChatView { Options = viewOptions };
chat.AddMessage(new PuraChatMessage
{
    Role = PuraChatRole.User,
    Markdown = "我的账单为什么多了 20 元？",
});

var session = chat.BeginStreamingMessage();
await session.AppendAsync("我先查一下…".AsMemory());
await session.CompleteAsync(); // 完成：更新同一 message 并加入/更新历史

chat.AbortStreaming();                 // 中断：保留部分内容，Status=Aborted
var snapshot = chat.CreateSnapshot();  // 会话持久化
var json = PuraChatSnapshotSerializer.Serialize(snapshot);
```

- 消息级虚拟化，1000 条历史不会全部实例化；
- 支持 `InsertMessage/UpdateMessage/RemoveMessage/ReplaceMessages` 与 `MessageAdded/Updated/Removed`；
- `AutoScrollMode`：`Never/NearBottom/Always`；
- `Metadata`/`ContentVersion`/`CreatedAt`/`UpdatedAt`/`Error` 供宿主会话管理；
- 未使用 `PuraChatView` 时，可按 Demo 的 `VirtualizedChatWindow` 自行实现同等模式。

## 6. 常用能力

### 6.1 文本选择/复制

```csharp
Options = new PuraMarkdownOptions
{
    Pipeline = pipeline,
    EnableTextSelection = true,
};

string text = view.GetPlainText();
await view.CopyAllAsync();
```

### 6.2 Agent 状态持久化

```csharp
// 保存
var json = PuraInteractionStates.Serialize(view.InteractionStates.Values);

// 恢复（自动重渲染）
view.ApplyInteractionStates(PuraInteractionStates.Deserialize(json));
```

### 6.3 大纲/锚点

```csharp
var outline = view.GetOutline();        // Level/Text/Anchor
view.ScrollToAnchor("section-2");
```

### 6.4 链接/图片事件

```csharp
view.LinkClicked += (_, e) => { e.Handled = true; /* 自定义打开 */ };
view.ImageLoading += (_, e) => { };
view.ImageLoaded += (_, e) => { /* e.Result */ };
```

### 6.5 本地化

```csharp
Options = new PuraMarkdownOptions
{
    Pipeline = pipeline,
    Localizer = new MyEnglishLocalizer(), // 默认 ChinesePuraLocalizer
};
```

### 6.6 块级虚拟化（单条超长消息）

```csharp
Options = new PuraMarkdownOptions
{
    Pipeline = pipeline,
    EnableBlockVirtualization = true, // 控件自带 ScrollViewer，勿再外层包裹
};
```

### 6.7 安全预算

```csharp
Limits = new PuraLimits
{
    MaxDocumentChars = 2 * 1024 * 1024,
    MaxBlocks = 3000,
    MaxNestingDepth = 64,
    MaxFenceChars = 256 * 1024,
};
```

超限会降级并触发 `Warning`（`PURA-LIM-*`），不会抛异常。`PuraLimits` 在 `PuraMarkdown.Core` 包（命名空间 `PuraMarkdown.Core.Security`），需要 `using PuraMarkdown.Core.Security;`。

## 7. 线程与生命周期

| 操作 | 线程 |
| --- | --- |
| 创建 View/设置 Options/Markdown | UI 线程 |
| `Append` / `AppendAsync` | UI 线程（内部入队） |
| `CompleteAsync` / `AbortAsync` | 可后台线程（内部回 UI） |
| `GetOutline/GetPlainText/ScrollTo...` | UI 线程 |
| `Dispose` | UI 线程；取消活动会话 |

建议在窗口关闭时调用 `view.Dispose()`；聊天列表移除消息时无需手动释放历史 View（由虚拟化容器管理）。

## 8. 常见坑

1. **启用块级虚拟化后不要再套 `ScrollViewer`**，否则双滚动/虚拟化失效。
2. **Agent 能力默认未启用**：不调用 `UseAgentComponents()` 时 `pura-agent` 只是普通代码块（能力在 `PuraMarkdown.Agent` 包内，无需额外引包）。
3. **流式完成前组件/代码高亮可能显示占位/纯文本**，`CompleteAsync` 后呈现最终效果。
4. **`MaxDocumentChars` 是字符数预算**，超长账单/日志请宿主先裁剪或分条渲染。
5. **主题切换**：`FollowSystemTheme=true` 会自动重渲染；否则切换后调用 `RefreshTheme()`。
6. **自定义围栏**：使用 `IFenceRenderer`，不要再实现已删除的 `IDiagramRenderer`。
7. **包版本**：`PuraMarkdown.Core`、`PuraMarkdown.Agent`、`PuraMarkdown.Extension` 必须同版本，避免类型/契约不匹配。
8. **`PuraChatView` 先设置 `Options` 再添加消息**，否则首次实例化可能没有渲染配置。
9. **Agent 状态恢复**：保存 `view.InteractionStates.Values`；恢复用 `ApplyInteractionStates`，不要只设置控件属性。
