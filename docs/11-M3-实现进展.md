## 3. 流式行为说明（M3 语义）

1. `Append` 只在**稳定边界**之前提交块；列表/引用/表格/缩进代码/未闭合围栏留在尾部窗口。
2. 尾部窗口每次追加都重新解析并替换控件；稳定块永不重解析。
3. 尾部超过 `TailWindowChars`（默认 16KB）时，在最近空行强制提交（由 `Complete` 全量校正兜底）。
4. `Complete` 做一次全量解析，保证与一次性渲染逐字节等价（测试覆盖 4 个随机切分种子）。
5. 已知限制：流式期间引用链接定义（`[id]: url`）跨窗口时可能延迟解析，`Complete` 后校正；交互组件在流式期间禁用。

## 4. Mermaid 引擎选型

- **采用 Mermaider 0.15.1**（MIT、纯 .NET、net10.0、无浏览器/DOM、AOT-ready）；M3 用其 ASCII 渲染显示。
- **Naiad 2.0.1 排除**：NuGet 许可证为文件型 EULA（OsmfEula.txt，All rights reserved），不符合宽松许可约束。
- SVG 显示留作后续（`Avalonia.Svg.Skia` 或 `Svg.Skia` 光栅化），契约不变。详见 [ADR-0023](adr/0023-mermaid-engine-mermaider.md)。
