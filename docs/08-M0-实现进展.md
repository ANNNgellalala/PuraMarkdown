## 3. 与设计文档的偏差（M0 范围裁剪，均不改变契约）

| 项 | 设计 | M0 实现 | 计划 |
| --- | --- | --- | --- |
| `pura-agent` AST 节点 | 自定义 `BlockParser` → `PuraAgentBlock` | 先用 `FencedCodeBlock.Info` 拦截（`AgentComponentRenderer` priority 100） | M1 补 `PuraAgentBlockParser`（FR-103），对外行为不变 |
| 流式算法 | 稳定边界 + 尾部窗口 | 全量解析 + 块级复用（正确性优先） | M3 接入稳定边界扫描，接口不变 |
| JSON Schema | `JsonSchema.Net` 校验 | 手写校验 + 第一条错误路径 | M1 接入 schema，保留错误定位格式 |
| 链接点击 | `ILinkHandler` | 仅样式 + 安全过滤，不触发打开 | M1 接入点击与 `ILinkHandler` |
| 图片 | 异步 `IImageLoader` | 占位文本 | M1 异步加载 |
| 任务列表 | CheckBox | `☐/☑` 文本符号 | M1 改为只读 CheckBox |
| 主题 | 跟随系统 | 显式 Light/Dark | M1 跟随系统 |
| golden 快照 | 文件化快照 | 内嵌期望字符串（1 条） | M1 扩展为文件化 golden 集 |

## 4. 下一步（M1）

1. `PuraAgentBlockParser`：识别 `pura-agent` 围栏 → `PuraAgentBlock`（IsClosed/Span），替换 M0 的 Info 拦截。
2. `JsonSchema.Net` 接入：choice/confirm schema + 首条错误定位。
3. 链接点击（`ILinkHandler`）、图片异步加载（`IImageLoader`）、任务列表 CheckBox。
4. 主题跟随系统 + A11y 语义（RadioButton/CheckBox 原生语义已具备，补键盘与播报）。
5. 扩展测试：golden 文件化、快捷键、A11y 断言。
