# ADR-0013：目标框架升级为 net10.0

- 状态：已接受（取代 ADR-0005）
- 日期：2026-11-05
- 关联：路线图 §1、需求 NFR-08

## 背景

v0.2 决定 net8.0 单目标（由 Avalonia 12 / Markdig 1.5.1 的最低要求派生）。用户明确要求：使用本机最新 .NET（10.0.114），不要 .NET 8；基础依赖取最新版本。

## 决策

**全部包与示例统一 `net10.0` 单目标**；`global.json` 锁定 SDK `10.0.114`（`rollForward: latestFeature`）。

## 理由

- 本机已安装 10.0.114；Avalonia 12.1.5 nuspec 提供 `net10.0` 资产；Markdig 1.5.1 提供 net10.0 资产。
- 可用最新 BCL 与 C# 语言特性（集合表达式、`params` 集合、`field` 关键字等），减少胶水代码。
- 用户明确要求；单目标避免多目标构建矩阵。

## 后果

- 宿主必须 .NET 10+；1.0 不承诺 .NET 8/9 宿主（若需要，另立多目标 ADR，成本约 3–5 人日）。
- AOT/裁剪验证以 net10.0 为唯一基线。
- 依赖版本随之取最新（见路线图版本基线）：Avalonia 12.1.5、DI 10.0.14、JsonSchema.Net 9.6.0 等。

## 备选

多目标 `net10.0;net9.0;net8.0`：仅在出现明确宿主需求时采用。
