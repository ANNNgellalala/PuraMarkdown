# 迁移指南：0.1.0-alpha.1（Agent 插件化 / 公共 API 收敛）

> 适用：已经引用旧版 `PuraMarkdown`（Agent 在核心、`IDiagramRenderer` 时代）或 3 包时代 `PuraMarkdown.Syntax` / `PuraMarkdown` / `PuraMarkdown.Plugins` 的宿主。
> 当前版本允许破坏性变更；按下面清单逐项修改即可（含 2026-11-10 的包改名，见 [ADR-0028](adr/0028-package-identity-rename.md)）。

---

## 1. 包引用

当前官方只发 3 个包，统一版本 `0.1.0-alpha.1`：

```xml
<PackageReference Include="PuraMarkdown.Agent" Version="0.1.0-alpha.1" /><!-- 传递引入 PuraMarkdown.Core -->
<PackageReference Include="PuraMarkdown.Extension" Version="0.1.0-alpha.1" />  <!-- 可选：代码高亮 + Mermaid -->
<!-- 服务端/无头纯解析场景只需引 PuraMarkdown.Core（无 Avalonia 依赖） -->
```

迁移分两段：先「7 个包 → 3 个包」（ADR-0027），再「3 个包改名 + 命名空间对齐」（ADR-0028）。第二段之后**没有裸 `PuraMarkdown` 包，也没有裸 `PuraMarkdown` 命名空间**：宿主必须同时修改 `PackageReference` 与 `using`。

### 1.1 第一段：7 个包 → 3 个包（ADR-0027）

| 旧包（7 包时代） | 现在 |
| --- | --- |
| `PuraMarkdown.Agent`（当时的独立包） | 并入 `PuraMarkdown.Agent`（Agent 组件现随渲染包提供，不再单独成包） |
| `PuraMarkdown.Chat` | 并入 `PuraMarkdown.Agent` |
| `PuraMarkdown.Testing` | 并入 `PuraMarkdown.Agent` |
| `PuraMarkdown.Highlighting.ColorCode` | 并入 `PuraMarkdown.Extension` |
| `PuraMarkdown.Diagrams.Mermaid` | 并入 `PuraMarkdown.Extension` |

### 1.2 第二段：3 个包改名 + 命名空间变更（ADR-0028）

| 旧包（3 包时代） | 新包 | 命名空间变化 |
| --- | --- | --- |
| `PuraMarkdown.Syntax` | `PuraMarkdown.Core` | `PuraMarkdown.Syntax` 与原根命名空间 → `PuraMarkdown.Core`；`PuraMarkdown.Security` → `PuraMarkdown.Core.Security` |
| `PuraMarkdown` | `PuraMarkdown.Agent` | `PuraMarkdown`、`PuraMarkdown.Rendering`、`PuraMarkdown.Localization`、`PuraMarkdown.Platform`、`PuraMarkdown.Chat`、`PuraMarkdown.Testing` → `PuraMarkdown.Agent` / `PuraMarkdown.Agent.*` |
| `PuraMarkdown.Plugins` | `PuraMarkdown.Extension` | `PuraMarkdown.Highlighting.ColorCode` → `PuraMarkdown.Extension.Highlighting.ColorCode`；`PuraMarkdown.Diagrams.Mermaid` → `PuraMarkdown.Extension.Diagrams.Mermaid` |

### 1.3 `using` 变化示例

```csharp
// 旧（3 包时代；7 包时代的 using 同样是这些名字）
using PuraMarkdown;                                // 控件、管道、选项、主题
using PuraMarkdown.Chat;                           // PuraChatView / PuraChatMessage
using PuraMarkdown.Testing;                        // ControlTreeDumper / GoldenFile
using PuraMarkdown.Syntax;                         // PuraDocument / PuraSyntaxBuilder
using PuraMarkdown.Highlighting.ColorCode;         // ColorCodeHighlighter
using PuraMarkdown.Diagrams.Mermaid;               // MermaidDiagramRenderer

// 新
using PuraMarkdown.Agent;                          // 控件、管道、选项、主题、Agent 组件
using PuraMarkdown.Agent.Chat;                     // PuraChatView / PuraChatMessage
using PuraMarkdown.Agent.Testing;                  // ControlTreeDumper / GoldenFile
using PuraMarkdown.Core;                           // PuraDocument / PuraSyntaxBuilder
using PuraMarkdown.Extension.Highlighting.ColorCode;
using PuraMarkdown.Extension.Diagrams.Mermaid;
```

`JsonSchema.Net` 现由 `PuraMarkdown.Agent` 依赖（`pura-agent` 组件随包提供），不再需要为 Agent 单独加包。背景与取舍见 [ADR-0027](adr/0027-package-consolidation.md) 与 [ADR-0028](adr/0028-package-identity-rename.md)。

## 2. Agent

### 2.1 `UseAgentComponents` 改为 Agent 扩展方法

```csharp
// 旧
var pipeline = new PuraPipelineBuilder()
    .UseCommonMark()
    .UseGfm()
    .UseAgentComponents()
    .Build();

// 新
using PuraMarkdown.Agent;

var pipeline = new PuraPipelineBuilder()
    .UseCommonMark()
    .UseGfm()
    .UseAgentComponents()   // 扩展方法，注册 AgentPlugin
    .Build();

// 或显式：
.UsePlugin(new AgentPlugin())
```

### 2.2 自定义 Agent 组件

```csharp
// 旧（核心 builder API）
builder.UseAgentComponentParser(new RatingParser());
builder.UseAgentComponentRenderer(new RatingRenderer());

// 新
builder.UseAgentComponent(new RatingParser(), new RatingRenderer());
```

多个插件可组合注册；内置 choice/confirm 自动包含。

### 2.3 删除的自定义 AST

`PuraAgentBlock` / `PuraAgentBlockParser` / `PuraAgentExtension` 不再存在。
自定义 `pura-agent` 语义请用 **`IFenceRenderer`**（语言 `pura-agent`）或内置 Agent 组件扩展（命名空间 `PuraMarkdown.Agent`）。

### 2.4 状态事件

`PuraInteractionEventArgs` / `IPuraInteractionStateReceiver` 仍在渲染包（命名空间 `PuraMarkdown.Agent`），事件不变。

## 3. 图表/围栏插件

`IDiagramRenderer` / `UseDiagramRenderer` / `CanRenderDiagram` / `RenderDiagram` 已删除，改为 `IFenceRenderer`：

```csharp
// 旧
public sealed class MyDiagramRenderer : IDiagramRenderer
{
    public bool CanRenderDiagram(string language, string source, RenderContext context) => ...;
    public Control RenderDiagram(string language, string source, RenderContext context) => ...;
}

builder.UseDiagramRenderer(new MyDiagramRenderer());

// 新
public sealed class MyDiagramRenderer : IFenceRenderer
{
    public string Name => "my.diagram";
    public bool CanRender(string language, string source, bool isClosed, RenderContext context) => ...;
    public Control Render(string language, string source, bool isClosed, RenderContext context) => ...;
}

builder.UseFenceRenderer(new MyDiagramRenderer());
```

- `isClosed` 由渲染层（`PuraMarkdown.Agent` 包）根据 Markdig 围栏闭合状态提供；
- 流式未闭合可用 `context.IsTail` / `isClosed` 返回占位；
- Mermaid 官方插件已迁移到 `PuraMarkdown.Extension` 包（命名空间 `PuraMarkdown.Extension.Diagrams.Mermaid`），宿主只需引用该包并 `using` 新命名空间。

## 4. 配置/生命周期 API

| 旧 | 新 |
| --- | --- |
| `builder.UseLimits(x => ...)` | `new PuraMarkdownOptions { Limits = new PuraLimits { ... } }` |
| `new PuraMarkdownOptions { Logger = ... }` | 删除（后续日志 API 重新设计） |
| `new PuraStreamingOptions { EnableBlockReuse = ... }` | 删除（块复用已默认启用） |
| `IPuraPlatformServices` / `DefaultPlatformServices` | 删除；直接设置 `ImageLoader`/`LinkHandler`/`Clipboard` |
| `PuraRendererRegistry.Registrations` | `PuraRendererRegistry.Renderers` |
| `PuraMarkdownOptions.Pipeline` | 不变 |

新增可选：

```csharp
view.ActiveSession
view.IsStreaming
view.AbortStreaming()
view.Dispose()
view.GetOutline()
view.GetPlainText()
await view.CopyAllAsync()
view.ScrollToAnchor("anchor")
```
