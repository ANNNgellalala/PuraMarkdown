# 迁移指南：0.1.0-alpha.1（Agent 插件化 / 公共 API 收敛）

> 适用：已经引用旧版 `PuraMarkdown`（Agent 在核心、`IDiagramRenderer` 时代）的宿主。
> 当前版本允许破坏性变更；按下面清单逐项修改即可。

---

## 1. 包引用

新增并保持同版本：

```xml
<PackageReference Include="PuraMarkdown" Version="0.1.0-alpha.1" />
<PackageReference Include="PuraMarkdown.Agent" Version="0.1.0-alpha.1" />
```

可选：`PuraMarkdown.Chat`、`PuraMarkdown.Highlighting.ColorCode`、`PuraMarkdown.Diagrams.Mermaid`。

核心包**不再依赖** `JsonSchema.Net`；Agent 包依赖它。

---

## 2. Agent

### 2.1 `UseAgentComponents` 改名/移包

```csharp
// 旧
var pipeline = new PuraPipelineBuilder()
    .UseCommonMark()
    .UseGfm()
    .UseAgentComponents()
    .Build();

// 新
using PuraMarkdown.Agent;

var pipeline = new PuraPipelineBuilder()
    .UseCommonMark()
    .UseGfm()
    .UseAgentComponents()   // 扩展方法，注册 AgentPlugin
    .Build();

// 或显式：
.UsePlugin(new AgentPlugin())
```

### 2.2 自定义 Agent 组件

```csharp
// 旧（核心 builder API）
builder.UseAgentComponentParser(new RatingParser());
builder.UseAgentComponentRenderer(new RatingRenderer());

// 新
builder.UseAgentComponent(new RatingParser(), new RatingRenderer());
```

多个插件可组合注册；内置 choice/confirm 自动包含。

### 2.3 删除的自定义 AST

`PuraAgentBlock` / `PuraAgentBlockParser` / `PuraAgentExtension` 不再存在。
自定义 `pura-agent` 语义请用 **`IFenceRenderer`**（语言 `pura-agent`）或 Agent 包的组件扩展。

### 2.4 状态事件

`PuraInteractionEventArgs` / `IPuraInteractionStateReceiver` 仍在核心（命名空间 `PuraMarkdown`），事件不变。

## 3. 图表/围栏插件

`IDiagramRenderer` / `UseDiagramRenderer` / `CanRenderDiagram` / `RenderDiagram` 已删除，改为 `IFenceRenderer`：

```csharp
// 旧
public sealed class MyDiagramRenderer : IDiagramRenderer
{
    public bool CanRenderDiagram(string language, string source, RenderContext context) => ...;
    public Control RenderDiagram(string language, string source, RenderContext context) => ...;
}

builder.UseDiagramRenderer(new MyDiagramRenderer());

// 新
public sealed class MyDiagramRenderer : IFenceRenderer
{
    public string Name => "my.diagram";
    public bool CanRender(string language, string source, bool isClosed, RenderContext context) => ...;
    public Control Render(string language, string source, bool isClosed, RenderContext context) => ...;
}

builder.UseFenceRenderer(new MyDiagramRenderer());
```

- `isClosed` 由核心根据 Markdig 围栏闭合状态提供；
- 流式未闭合可用 `context.IsTail` / `isClosed` 返回占位；
- Mermaid 官方插件已迁移，无需宿主改动（只需升级包）。

## 4. 配置/生命周期 API

| 旧 | 新 |
| --- | --- |
| `builder.UseLimits(x => ...)` | `new PuraMarkdownOptions { Limits = new PuraLimits { ... } }` |
| `new PuraMarkdownOptions { Logger = ... }` | 删除（后续日志 API 重新设计） |
| `new PuraStreamingOptions { EnableBlockReuse = ... }` | 删除（块复用已默认启用） |
| `IPuraPlatformServices` / `DefaultPlatformServices` | 删除；直接设置 `ImageLoader`/`LinkHandler`/`Clipboard` |
| `PuraRendererRegistry.Registrations` | `PuraRendererRegistry.Renderers` |
| `PuraMarkdownOptions.Pipeline` | 不变 |

新增可选：

```csharp
view.ActiveSession
view.IsStreaming
view.AbortStreaming()
view.Dispose()
view.GetOutline()
view.GetPlainText()
await view.CopyAllAsync()
view.ScrollToAnchor("anchor")
```
