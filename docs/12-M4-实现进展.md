## 3. 安全语料覆盖

| 用例 | 期望行为 |
| --- | --- |
| `<script>alert(1)</script>` | 按字面文本渲染，无脚本/无 Button |
| 事件属性 HTML（`onclick`） | 字面文本 |
| `javascript:` 链接 | 不生成 `HyperlinkButton` |
| `data:image/png` 图片 | 拒绝并显示"图片被拒绝" |
| 超长文档（超 `MaxDocumentChars`） | 截断 + `PURA-LIM-001` warning |
| 200 层嵌套引用 | 不崩溃、内容可读 |
| 伪造交互选项 | 事件只可能来自已解析模型中的选项 id |

## 4. A11y

- 标题：`AutomationProperties.SetHeadingLevel`。
- 选择/确认组件：`AutomationProperties.SetName`（M1）+ 原生 RadioButton/CheckBox/Button 语义。
- 流式完成/中断：`Announced` 事件 + `LiveSetting=Polite`（宿主可转发平台播报器）。
- 对比度：浅/深主题的正文/背景对比度 ≥ 4.5:1（自动化校验）。
- 键盘：Space/Enter 触发交互（M3 测试）。
- 未做：真实屏幕阅读器（Narrator/TalkBack）手工实测、减少动效偏好。

## 5. 裁剪 / AOT

- **已验证**：`dotnet publish samples/PuraMarkdown.Spike -c Release -p:PublishTrimmed=true -p:TrimMode=link` 成功产出 `artifacts/trim-spike`。
- 裁剪后的二进制可直接运行，输出与未裁剪版本一致的控件树 dump（含 ColorCode / Mermaid / rating 插件）。
- Native AOT 未在本轮验证（需要 C++ 工具链与更长构建时间）；列为 1.0 发布前检查项。

**裁剪结果**：`PublishTrimmed` 构建 exit code 0，无阻断性警告；运行成功。
