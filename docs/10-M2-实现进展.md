## 4. 偏差与说明

- `ColorCodeHighlighter` 只把 token 映射到主题的 comment/keyword/string/number 四类；其余 token 显示为普通文本（V1 简化）。
- 图表插件目前是"占位渲染"（显示源码摘要），用于验证 `IDiagramRenderer` 契约与回退链；真实引擎选择保持 ADR-0007/ADR-0014 的"插件决定"原则。
- 渲染器回退链上限 8 次，防止插件互相回退导致死循环。
- `PuraMarkdown.Plugins.Samples` 是示例工程，不作为正式 NuGet 包发布。
