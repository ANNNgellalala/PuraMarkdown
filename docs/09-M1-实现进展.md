## 4. 与设计文档的偏差

- `IAgentComponentRenderer.RenderComponent` 的节点参数当前为 `MarkdownObject`（实际为 `PuraAgentBlock`），与设计中的 `PuraAgentBlock` 一致；接口保持宽类型以便未来兼容。
- 链接/图片通过 `InlineUIContainer` 承载控件，文本流中会作为"行内控件"参与排版；这是 Avalonia 的常规做法，但与纯 Run 的换行行为略有差异（M2 可评估更细的排版方案）。
- 未实现 `JsonSchema` 的 `$ref`/多文件 schema；当前 schema 内联在 `ComponentSchemas`。
