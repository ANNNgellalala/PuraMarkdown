## 1. 流式生命周期

```csharp
var session = view.BeginStreaming();
await session.AppendAsync("token".AsMemory(), cancellationToken);
await session.FlushAsync();      // 强制完成当前缓冲的解析 + UI 应用
await session.CompleteAsync(cancellationToken);

session.Completed += (_, _) => { };
session.Aborted += (_, _) => { };
```

新增：

| 成员 | 说明 |
| --- | --- |
| `AppendAsync(ReadOnlyMemory<char>, CancellationToken)` | 异步追加（宿主 token 流） |
| `FlushAsync()` / `WaitForIdleAsync()` | 等待当前缓冲完成一次渲染 |
| `Completed` / `Aborted` 事件 | 无需持有 Task 即可感知终态 |
| `CompleteAsync(CancellationToken)` / `AbortAsync(CancellationToken)` | 支持取消 |
| `PendingChars` / `CurrentText` | 诊断与 plain-text 导出 |
| `PuraStreamingOptions.AutoScrollToEnd` | 块级虚拟化模式下自动跟随底部 |

## 2. 文本选择/复制

- `PuraMarkdownOptions.EnableTextSelection`：段落/标题/任务项/代码块使用 `SelectableTextBlock`。
- `PuraMarkdownView.GetPlainText()`：从 AST 提取纯文本（不引入 IR）。
- `PuraMarkdownView.CopyAllAsync(CancellationToken)`：复制纯文本到剪贴板。

## 3. 大纲、锚点与滚动

```csharp
IReadOnlyList<PuraHeadingInfo> outline = view.GetOutline();
bool ok = view.ScrollToAnchor("second"); // 可带前导 #
```

- 锚点由标题文本生成（去标点、空格转 `-`、重名追加序号）；
- 非虚拟化模式 `BringIntoView()`；块级虚拟化模式使用估算偏移。

## 4. 链接/图片事件

```csharp
view.LinkClicked += (_, e) => { e.Handled = true; }; // 阻止默认 ILinkHandler
view.ImageLoading += (_, e) => { };
view.ImageLoaded += (_, e) => { /* e.Result: Success/Refused/Failed */ };
```

默认行为不变：未设置 `Handled` 时仍调用 `ILinkHandler`；图片仍走 `IImageLoader`。

## 5. 主题实时切换

- 订阅 `ActualThemeVariantChanged`：`FollowSystemTheme=true` 时自动重渲染；
- 新增 `RefreshTheme()` 供宿主手动触发。

## 6. 本地化（默认中文）

```csharp
public IPuraLocalizer Localizer { get; init; } = ChinesePuraLocalizer.Instance;
```

- 内置 `ChinesePuraLocalizer`（中文默认）；
- `PuraStringKeys` 公开全部文案键；
- 宿主可实现 `IPuraLocalizer` 替换（示例测试用英文）：
  ```csharp
  var options = new PuraMarkdownOptions
  {
      Pipeline = pipeline,
      Localizer = new MyEnglishLocalizer(),
  };
  ```
- 已本地化：代码复制/复制状态/自动化名称、图片占位与加载状态、Agent 组件加载/校验/渲染错误、choice 选择数量提示、流式完成/中断播报。
- 诊断 warning 的 code 保持稳定（`PURA-*`），消息暂保持中文（便于现有测试/日志检索）；后续可继续迁移。
